    bk_pwm_set_period_duty(pwm_chan_t chan, pwm_period_duty_config_t *config)

    ¶

    Function:¶

    • Config PWM period and duty cycle.
    • This API is used to configure the period and duty time. The unit is cycle of PWM channel clock,since the PWM channel clock is default to 26M, the unit is 1/26M (1/26 000 000) seconds.
    • The beken chip supports up to 3 duties, the exact duty numbers depends on the target type.

    notice:¶

    • Example1-the simplest case:
                Clock cycle = 1/26M
            Initial signal is High
            duty_cycle = D1 = 3
            duty2_cycle = 0
            duty3_cycle = 0
            period_cycle = 3 + 2 = 5
                                    __    __    __    __    __    __    __    __    __    __    __    __
            Clock Signal:   __|  |__|  |__|  |__|  |__|  |__|  |__|  |__|  |__|  |__|  |__|  |__|  |__
                                     ____________                  ____________                 _______
            PWM Signal:    __|                  |___________|                 |___________|

            Duty1:           |<------- D1 ----->|

            Period:          |<---------- Period1 --------->|<------ Period2 ------------>|

    Example2 - 3 duty with initial signal high:

            Clock cycle = 1/26M
        duty_cycle = D1 = 1
        duty2_cycle = D2 = 2
        duty3_cycle = D3 = 3
        period_cycle = 1 + 2 + 3 = 6

    Example3 - 3 duty with initial signal low:

                Clock cycle = 1/26M
            duty_cycle = D1 = 1
            duty2_cycle = D2 = 2
            duty3_cycle = D3 = 3
            period_cycle = D1 + D2 + D3 = 6

    • Example4 - 3 duty with initial signal low and period > (D1 + D2 + D3):
            Clock cycle = 1/26M
        duty_cycle = D1 = 1
        duty2_cycle = D2 = 2
        duty3_cycle = D3 = 3
        period_cycle = D1 + D2 + D3 + 1 = 7

    attention:¶

    • The period should great or equal to (D1 + D2 + D3)
    • If the duty Dx is 0, then Dx+1 to D3 should also be 0. If D1 is 0, it indicates the duty ratio is 0% and the signal is always low.
    • If D1 equals period, it indicates the duty ratio is 100% and the signal is always high.
    • The signal strengh between two successive duties is opposite, e.g. if signal of D1 is high, then signal of D2 is low.
    • The initial signal is the signal strengh of D1 if D1 is not 0.
    • The duty/period configuration is very flexible, different configurations may have same result.
    return:
    • BK_OK: succeed
    • BK_ERR_NULL_PARAM: config is NULL
    • BK_ERR_PWM_CHAN_NOT_INIT: PWM channel not init
    • BK_ERR_PWM_CHAN_ID: invalid PWM channel
    • BK_ERR_PWM_PERIOD_DUTY: PWM duty/period relationship is invalid
    • others: other errors
